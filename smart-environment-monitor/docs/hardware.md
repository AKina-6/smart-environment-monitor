# 硬件设计

## 1. 器件清单

| 器件 | 数量 | 作用 |
|---|---:|---|
| STM32F103C8T6 最小系统板 | 1 | 主控制器 |
| DHT11 | 1 | 温湿度采集 |
| BH1750 | 1 | 光照强度采集 |
| SSD1306 OLED | 1 | 本地数据显示 |
| 有源蜂鸣器 | 1 | 声音报警 |
| LED + 220 Ω 电阻 | 1 | 状态指示 |
| USB 转串口模块 | 1 | 调试与遥测 |
| ESP8266 | 1 | 无线通信，可选 |
| 4.7 kΩ 电阻 | 1 | DHT11 数据线上拉 |

## 2. 接线表

| 模块引脚 | STM32F103C8T6 |
|---|---|
| DHT11 DATA | PA0 |
| BH1750 SCL | PB6 / I2C1_SCL |
| BH1750 SDA | PB7 / I2C1_SDA |
| OLED SCL | PB6 / I2C1_SCL |
| OLED SDA | PB7 / I2C1_SDA |
| LED | PB0 |
| Buzzer | PB1 |
| UART TX | PA9 |
| UART RX | PA10 |

## 3. 电气注意事项

- STM32F103C8T6 使用 3.3 V 逻辑电平。
- DHT11 数据线建议增加 4.7 kΩ 上拉电阻。
- I²C 总线上的 OLED 和 BH1750 可以共享 SCL/SDA，但地址不得冲突。
- 蜂鸣器电流超过 GPIO 驱动能力时，应使用三极管或 MOSFET。
- ESP8266 峰值电流较高，应使用稳定的独立 3.3 V 电源。
- 所有模块必须共地。

## 4. 建议测试顺序

1. 验证串口输出。
2. 单独验证 OLED。
3. 单独验证 BH1750。
4. 单独验证 DHT11。
5. 接入 LED 和蜂鸣器。
6. 最后接入 ESP8266。
