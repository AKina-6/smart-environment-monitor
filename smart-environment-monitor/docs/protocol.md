# 串口遥测协议

## 参数

- 波特率：115200
- 数据位：8
- 停止位：1
- 校验：None
- 行结束：建议 `\r\n`

## JSON 格式

```json
{
  "timestamp_ms": 1000,
  "temperature_c": 25.4,
  "humidity_pct": 61.0,
  "light_lux": 420.0,
  "alarm_mask": 0
}
```

## 报警位

| 位 | 十六进制 | 含义 |
|---:|---:|---|
| 0 | 0x01 | 温度过高 |
| 1 | 0x02 | 湿度过高 |
| 2 | 0x04 | 光照过低 |
| 3 | 0x08 | 传感器故障 |

多个报警可以按位组合。例如 `alarm_mask = 5` 表示温度过高且光照过低。
