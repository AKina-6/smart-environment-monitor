# 简历项目描述

## 简洁版

**基于 STM32 的智能环境监测系统**

基于 STM32F103C8T6 完成温湿度与光照数据采集、OLED 显示、阈值报警和 UART 遥测；采用模块化 C 语言架构分离业务逻辑、设备驱动和硬件平台，并使用 CMake、单元测试及 GitHub Actions 验证核心逻辑。

## 详细版

- 基于 STM32F103C8T6 设计智能环境监测终端，集成 DHT11、BH1750、SSD1306 OLED、LED 和蜂鸣器。
- 实现温湿度与光照周期采集、实时显示、阈值判断和多报警位组合。
- 设计 JSON 串口遥测协议，便于上位机或 ESP8266/MQTT 模块接入。
- 使用分层架构将应用逻辑与 STM32 HAL 解耦，使核心算法可在电脑端编译运行。
- 使用 CMake 建立模拟程序和单元测试，并通过 GitHub Actions 自动执行编译检查。

## 面试讲解重点

1. 为什么把报警逻辑设计成纯 C 模块。
2. I²C 总线共享时如何避免 OLED 和 BH1750 冲突。
3. DHT11 对微秒级时序的要求。
4. 阈值报警如何扩展迟滞，避免频繁开关。
5. 裸机主循环如何迁移到 FreeRTOS。
6. 传感器故障、串口阻塞和看门狗如何处理。
